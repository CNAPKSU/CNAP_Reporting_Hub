Computing infrastructure

The core is integrated with Beocat, the Kansas State University high-performance computing cluster in the Carl R. Ice College of Engineering.

Beocat cluster
More than 10,000 shared compute cores

CONNECT Lab

A separate facility, with support from two cores

Cog + Neuro Network for Experimentation and Computing Technologies. A staffed drop-in room, BH 444, with four workstations for R, MATLAB, Python, JMP, PsychoPy, Unity, and more.

Experiment assistanceThrough the Cognitive Neuroscience Core: experiment programming and design consultation, hardware integration with EEG, TMS, eye tracking, and response devices, help adapting existing scripts, and shared experiment code and templates.
Data assistanceThrough the Neuroinformatics Core: data pipelines and analysis consultation, workflows for large-scale and parallel analysis on Beocat, machine learning help, and workshops on analysis tools and methods.

Working with the core

  1. Book a consultationDescribe your data and your question. The core helps you choose an approach and estimate the computing you need.
  2. Get accessThe core sets up your Beocat account and secure data transfer, and points you to training if you need it.
  3. Run your analysisWork on your own with core support, or ask the core to build the pipeline with you.
  4. Cite the coreAcknowledge CNAP and the Neuroinformatics Core in publications and presentations that used its resources.

Questions about the Neuroinformatics Core go to dcaragea@ksu.edu.
General questions go to cnap@ksu.edu.
